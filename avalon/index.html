RULES · 玩法

一局是这样走完的

先说结论：好人完成 3 次任务就赢（但还得躲过刺客的最后一击）；坏人破坏 3 次任务就赢，或者靠最后指认梅林翻盘。

胜负条件速记：好人赢 = 3 次任务成功 + 刺客指认失败（或坏人从未拿到 3 分）；坏人赢 = 3 次任务失败， 或同一轮里连续 5 次组队被否决，或终局指认对了梅林。

PLAY ONLINE · 在线开局

不用买牌，手机就能开一局

站长（上帝）建房 → 朋友输入房间码入场（不用注册账号）→ 坐满后一键发身份 → 每个人的手机屏幕上显示自己的身份牌、自己能看见谁、看不见谁。

📱 在线开局怎么用

  1. 站长打开开局页、登录站长账号，选人数（5~10 人）后建房；
  2. 把屏幕上的房间码 / 二维码给身边的朋友；
  3. 朋友用手机打开同一页、输入房间码和昵称就能入座；
  4. 坐满后站长点「开始发牌」—— 身份只在服务端洗，每个人的手机上只会显示他自己的那份；
  5. 查看身份需要按住屏幕，松手即遮挡，防止旁边的狼看到；
  6. 上帝面板能推进流程、记录任务成败、最后公开全部身份复盘。

🧭 为什么不用线上房间也能玩

这个工具只负责两件事：发身份 和 记分。 说话、投票、使眼色、拍桌子，还是在线下面对面完成 —— 手机上不会替你们说话。

房间里不要求玩家注册账号：进门只需要一个昵称。 房主是本站站长，房间状态存在他的账号下，24 小时后自动过期回收。

小提示：8 个人围一桌，屏幕上只会显示你自己的身份 —— 想看，按住；松手，就盖回牌背。
