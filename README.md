## 功能模块

| 模块 | 说明 |
| --- | --- |
| 💬 说说墙 | 时间线展示短动态（可编辑 / 删除） |
| 🧳 旅行日志 | 卡片网格展示游记，可增删改 |
| 📷 数码生活 | 时间线展示数码产品体验与评分 |
| 🍵 留言 & 友链 | 公开留言 + 邮件通知站长；友链可增删改 |
| 👤 账号体系 | 站长发放账号密码；访客登录后按权限（可编辑/仅查看）呈现界面 |
| 🛡️ 管理面板 | 新建账号、设置权限、授权/取消管理员、重置密码、删除 |

## 架构（v5）

```
静态页面（GitHub Pages，零密钥）
  ├─ 游客：留言（公开）
  ├─ 访客：账号+密码登录（站长发放）→ 按权限可编辑/仅查看
  └─ 站长 MiNgAltair：全部功能 + 管理面板
          ↓ 全部经 Cloudflare Worker（凭证仅存服务端）
GitHub minghz-db/db.json（内容数据 + 账号数据[密码 PBKDF2 哈希]）
          ↓
私有 minghz-notify 仓库 Action → SMTP → 126 邮箱（新留言通知）
```

## 账号与权限

- 站长：MiNgAltair / woshihuangyanming（种子账号，可自行改密）
- 角色：owner（站长）> admin（管理员）> edit（可编辑）> view（仅查看）
- 登录限流：每 IP 每小时 12 次尝试；密码 PBKDF2-SHA256（60000 迭代+随机盐）
- 管理面板仅 owner 可创建/授权/删除；admin 可查看账号列表

## 安全管理

- 页面源码零密钥；登录/改密/发放账号全部经 Worker 服务端校验
- 所有数据变更走 git 提交历史，可回滚；内容修改需登录且具备可编辑权限
